What is real here, and what the build swaps in

This is the Phase 0 proof of concept from the plan: real station order and approximate ECML geography, a synthetic centreline, procedural terrain, and a synthetic per-link model that follows the plan's structure (Ofcom prior → terrain/cutting adjustment → cell-aware handovers → vehicle loss → link manager → passenger Wi-Fi).

  • Route: swap the spline for the OSM/Network Rail centreline via fetch_route.py → route_samples.parquet.
  • Cellular prior: replace the noise field with the Ofcom 50 m grid join (join_ofcom.py); keep raw category alongside score.
  • Cell sites: replace generated sites with OpenCellID corridor extract, top-5 candidates per sample.
  • Starlink: keep the obstruction model; feed it real DEM horizon + tunnel polygons; calibrate against terminal telemetry later.
  • Renderer: same layer set moves to GeoLibre (MapLibre terrain + deck.gl PathLayer/ColumnLayer, DuckDB-WASM for the popup queries).
  • Confidence: already carried per sample; values here are honest about being synthetic (0.2–0.45).
